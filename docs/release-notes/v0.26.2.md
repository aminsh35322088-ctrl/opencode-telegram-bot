# v0.26.2

## Topic reliability
- Hardened Topic keyboard routing so reserved controls never fall through into Coding AI prompts.
- Sending a new prompt while a Topic is paused now resumes the same OpenCode session with the actual instruction.
- Pause/resume state and keyboard state remain isolated per coding session.

## Image AI reliability
- Coding AI input is blocked while Image AI is generating or editing in the same session.
- Image AI operations now keep the correct session/workspace association even if active session context changes during processing.
- Image operations reliably return the session to idle after success or failure.

## Dependencies
- Removed duplicate `socks-proxy-agent` and `unified` dependency entries from `package.json`.

## Release
- Telegram Bot version: `v0.26.2`.
- `/start` and `/update` show the previous → current bot version and these release notes once per installed version.

Full changelog: https://github.com/aminsh35322088-ctrl/opencode-telegram-bot/compare/v0.26.0...v0.26.2
