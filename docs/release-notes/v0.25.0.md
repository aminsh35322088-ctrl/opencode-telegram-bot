# v0.25.0

## Versioning
- Added an independent Telegram Bot version, separate from the bundled OpenCode version.
- The bot now identifies itself as v0.25.0 while OpenCode remains independently versioned.

## Update notifications
- `/start` and `/update` detect a bot-version migration and show `previous → current`.
- The migration notification is persisted so the same update is not repeatedly announced.
- OpenCode update reporting remains separate from the bot release version.

## Version inventory
- Added `/all version info` to inspect the running stack.
- Reports the bot version, OpenCode version, Node.js/npm runtime, installed runtime dependencies, and integrated CLI/system tools such as Git, Git LFS, GitHub CLI, Railway CLI, Playwright CLI, pnpm, TypeScript, ESLint, Vitest, Python/pytest, SQLite, FFmpeg, ImageMagick, and common shell utilities when available.

## Settings release
- Replaced the obsolete Settings AI Rules entry with Model selection.
- Expanded Appearance controls, including runtime Message format (Markdown/Raw).
- Added persisted Message format state and regression coverage across Settings routing and rendering.

## Notes
- This release version belongs to the Telegram bot project and does not change the OpenCode release number.
