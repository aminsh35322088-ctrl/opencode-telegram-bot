# v0.26.0

## Telegram Topics
- Coding sessions now live in dedicated private Telegram Topics.
- Each Topic is bound to its own OpenCode session and isolated workspace.
- The main private chat is now a control center for starting sessions and configuration instead of a shared coding transcript.
- Added per-topic Pause, Resume, Abort, Model, Image AI, and Delete Chat controls.
- Topic routing survives bot restarts through lightweight session/topic bindings.

## Workspace and session isolation
- Every new coding Topic gets a dedicated working directory based on the configured project source.
- Session history, code changes, generated files, attachments, and local assets remain inside the Topic workspace.
- Topic deletion is scoped to the selected session, workspace, Telegram Topic, and binding; the main project is protected by path guards.

## Image AI
- Preserved the existing Generate Image and Edit Image flows inside Topics.
- Image AI mode is isolated per coding session to prevent cross-Topic state leakage.
- Generated and edited assets are stored in the Topic workspace for direct use by Coding AI.

## Reply context
- Replying to a Topic message now gives Coding AI the referenced text or caption.
- Replied photos and documents are downloaded into the Topic workspace and attached to the prompt without crossing Topic boundaries.

## Reliability and routing
- Topic-aware Telegram routing was added for streaming, tool output, callbacks, and progress messages.
- Pause state and keyboard state are scoped to individual sessions instead of being globally shared.
- Duplicate Topic creation for the same session is prevented with per-session single-flight handling.
- Callback routing resolves the Topic from the callback message itself, avoiding reliance on the current global chat context.

## Model Center and provider updates
- The canonical Model Center and live custom-provider model catalog improvements from the 0.25.x line are included in this release.
- Model labels remain clean and human-readable while provider-advertised names and searchable model IDs are preserved.

## Release
- Telegram Bot version: `v0.26.0`.
- OpenCode keeps its independent version lifecycle.
