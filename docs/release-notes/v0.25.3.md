# v0.25.3

## Model names
- Model Center now shows clean, human-readable model names only.
- Provider/company names are no longer repeated on individual model buttons.
- Provider-advertised names from the live `/models` catalog are preserved when available.
- Model search matches both model IDs and advertised names.

## Changelog delivery
- `/start` and `/update` now have an embedded release-notes fallback, so the current Changelog is available even when markdown release-note files are not present in the runtime image.
- Version state is written only after the update notice and Changelog are successfully sent.

## Tooling
- Updated model formatting regression coverage for the canonical model-only presentation.
