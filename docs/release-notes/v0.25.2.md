# v0.25.2

## Model Center 3
- Reworked Model Center around Favorites, Recent Models, provider browsing, and model search.
- Every model now has an independent ☆/⭐ favorite action, with favorite state shown directly beside the model name.
- Recent Models is a dedicated section and Search/Recent results show the provider beneath each model.
- Provider-specific model pages avoid repeating the provider name on every model button.
- Large provider catalogs are paginated and live custom-provider catalogs are refreshed automatically every 5 minutes, with an immediate refresh when Model Center opens.
- Custom-provider catalogs are authoritative, so changing a provider's API/model catalog no longer leaves stale model counts behind.
- Model action callbacks use short runtime tokens instead of embedding arbitrary model IDs.

## Versioning
- Bot release is now v0.25.2 and is separate from the bundled OpenCode version.
- `/start` detects the bot-version migration and sends the release changelog once for the new version.
- `/start` continues to display the running bot and OpenCode versions.
