# v0.25.2 — Model Center 3

Released 2026-09-04.

## Model Center 3

- Model selection is now served by one canonical Model Center.
- Favorites and Recent Models are persistent, with per-model `☆/⭐` controls.
- Search results show the provider beneath each model.
- Provider browsing is paginated and uses live catalogs.
- Custom-provider catalogs are authoritative and refresh automatically every 5 minutes, with an immediate refresh when Model Center opens.
- Model action callbacks use short runtime tokens with bounded in-memory state.
- The persistent bottom Model button opens the same Model Center used from Settings.
- Legacy model-selection UI and callback routing were removed.

## Custom Provider consistency

Model Center reads configured custom providers from the persistent custom-provider store. A provider change is reflected after the next live refresh instead of leaving stale OpenCode model counts in the selector.

## Update notification

After upgrading from an older installed bot version, `/start` displays the previous → current bot version and sends these release notes once for the new installed version.

`/start` also continues to show the running Telegram Bot and OpenCode versions.
